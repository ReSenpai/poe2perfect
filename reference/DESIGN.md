# PoE 2 Build Guide — дизайн расширения для Chrome

> Источник истины для визуала — концепт-арт
> [`Концепт расширения для PoE 2 билдов.png`](Концепт%20расширения%20для%20PoE%202%20билдов.png).
> Раскладка экранов по вкладкам — в [interface.md](interface.md).
>
> Пометка **(предложение)** означает, что в концепте этого нет и значение нужно согласовать.

Слоган концепта: **Less noise / More focus / Better builds**.

## 1. Что делаем

Расширение для Chrome, которое на странице билда Path of Exile 2 на целевом сайте
(по названию проекта — **mobalytics.gg**, уточнить) заменяет страницу чистым
минималистичным интерфейсом. Все данные билда — в одном месте, разложены по вкладкам.
Никакой рекламы, лишних блоков и отвлекающих элементов.

Расширение **не меняет данные** сайта: оно читает билд со страницы и показывает его
в своём интерфейсе. Пользователь всегда может вернуться к оригинальной странице.

## 2. Принципы

| Принцип | Что это значит на практике |
|---|---|
| **Минимализм** | Только нужная информация. Никакой рекламы, посторонних блоков и декоративных элементов. |
| **Удобная навигация** | Весь контент по вкладкам. Минимум скролла, максимум информации на экране. |
| **Данные под рукой** | Сводки, приоритеты, ключевые показатели — всегда на виду, не спрятаны в тексте. |
| **Чистый и стильный вид** | Тёмная тема, читаемые шрифты, акцент только на важном. |
| **Не ломает сайт** | Подменяет интерфейс на странице билда, не изменяя контент сайта; оригинал доступен в один клик. |

## 3. Цвета

### Базовая палитра (из концепта)

| Токен | HEX | Назначение |
|---|---|---|
| `--bg` | `#0E0F12` | Основной фон страницы |
| `--surface` | `#16181D` | Карточки, панели |
| `--border` | `#2A2D33` | Границы карточек, разделители, неактивные чипы |
| `--accent` | `#E8A15A` | Активная вкладка/вариант, номера приоритета, путь в дереве, кнопки |
| `--text` | `#E8E6D9` | Основной текст, заголовки |
| `--text-muted` | `#9AA0A6` | Вторичный текст: подписи, теги, моды, метаданные |

### Производные *(предложение)*

| Токен | Значение | Назначение |
|---|---|---|
| `--surface-hover` | `#1C1F25` | Наведение на карточку/строку |
| `--accent-soft` | `rgba(232, 161, 90, 0.12)` | Фон активного чипа и выбранной строки |
| `--accent-strong` | `#F0B478` | Наведение на акцентную кнопку |
| `--text-disabled` | `#5F646B` | Неактивные элементы, пустые слоты |

### Семантические *(предложение)*

Цвета используются только в иконках и маленьких маркерах, не в фонах.

| Токен | HEX | Где |
|---|---|---|
| `--res-fire` | `#E0703A` | Иконка огненного резиста |
| `--res-cold` | `#5AA9E6` | Иконка резиста к холоду |
| `--res-lightning` | `#E8C547` | Иконка резиста к молнии |
| `--res-chaos` | `#A57BD8` | Иконка резиста к хаосу |
| `--rarity-unique` | `#E8A15A` | Название уникального предмета (в концепте совпадает с акцентом) |
| `--rarity-rare` | `#E8D98A` | Название редкого предмета |
| `--rarity-magic` | `#8FA8FF` | Название магического предмета |
| `--rarity-normal` | `#E8E6D9` | Название обычного предмета |
| `--gem-str` / `--gem-dex` / `--gem-int` | `#D9534F` / `#5CB85C` / `#5B8DEF` | Обводка/иконка гемов по атрибуту |

Контраст: `--text` и `--text-muted` на `--surface` проходят WCAG AA для текста 12px+.
Акцент на тёмном фоне — только для текста от 13px и для графических элементов.

## 4. Типографика

Шрифт: **Inter**, запасной вариант — системный UI-шрифт:
`font-family: Inter, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;`
Цифры в статах — `font-variant-numeric: tabular-nums`.

Шрифт поставляется вместе с расширением, без загрузки с внешних CDN.

Уровни из концепта; размеры сняты с пропорций макета *(предложение)*:

| Уровень | Размер / межстрочный | Насыщенность | Где |
|---|---|---|---|
| Заголовок | 24 / 32 px | 600 | Название билда |
| Подзаголовок | 18 / 24 px | 600 | Заголовок карточки (Gear, Gear Priority, Active Skills) |
| Основной | 14 / 20 px | 400–500 | Вкладки, названия предметов и скиллов, пункты приоритета |
| Мелкий | 12 / 16 px | 400 | Теги, моды, подсказки, мета-строка, подписи слотов |

- Описание билда в шапке — мелкий/основной текст курсивом, `--text-muted`.
- Заголовки секций внутри карточек — без капса; капс в [interface.md](interface.md)
  только обозначает заголовки в ASCII-схемах.

## 5. Сетка, отступы, формы *(предложение)*

- Шаг отступов — **4px**: 4, 8, 12, 16, 24, 32.
- Внешний отступ контента — 24px; расстояние между карточками — 16px;
  внутренний отступ карточки — 16px (заголовок карточки — 20px сверху).
- Скругления: карточки и панели — 8px; чипы, кнопки, слоты предметов — 6px;
  номер приоритета — круг.
- Границы: 1px `--border`. Тени не используем — глубина задаётся фоном
  (`--bg` → `--surface`).
- Раскладка контента — две колонки (основная ~2/3 + боковая ~1/3);
  в Passives дерево занимает ~70%.
- Минимальная ширина окна — 1024px. Уже этого боковая колонка уходит под основную.

## 6. Иконки

- Простые контурные иконки в едином стиле: 20px, линия 1.5px, скруглённые концы.
- Цвет — `--text-muted`, у активного элемента — `--accent`.
- Набор из концепта: скилл (кисть/клинок), шлем, броня, кольцо, флакон,
  узлы дерева, документ.
- Соответствие вкладкам: Overview — инфо-круг, Skills — скилл, Gear — броня,
  Passives — узлы, Atlas Tree — карта, Progression — флакон.
- Готовый набор *(предложение)*: [Lucide](https://lucide.dev) (лицензия ISC),
  недостающие игровые иконки — дорисовать в том же стиле.
- Иконки предметов, гемов и арт класса — игровые изображения, берутся с исходной страницы.

## 7. Компоненты

### Шапка билда
Арт класса (квадрат ~96px, скругление 8px) · название (Заголовок) ·
`Класс / Асценданс` (Основной, асценданс — `--text-muted`) · мета-строка с иконками:
лига/патч, уровень, стадия. Справа, за вертикальным разделителем, — описание билда.
Шапка только информационная, кнопок в ней нет. Управление страницей — тихие иконки (без рамки, `--text-muted`,
фон при наведении) в правом конце строки вкладок: свернуть/развернуть шапку и «Show original page».
Свёрнутая шапка скрыта полностью; в строке вкладок перед иконками — название билда (`--text-muted`).

### Вкладки
Горизонтальная панель под шапкой, иконка + подпись. Активная: текст и иконка
`--accent`, подчёркивание 2px `--accent` на всю ширину вкладки. Нижняя граница
панели — 1px `--border`.

### Чипы вариантов
Подпись `Variant` + ряд чипов. Обычный: граница `--border`, текст `--text-muted`.
Активный: граница `--accent`, фон `--accent-soft`, текст `--accent`.

### Карточка
Фон `--surface`, граница 1px `--border`, скругление 8px, заголовок-подзаголовок
в левом верхнем углу.

### Слот предмета
Иконка предмета (квадрат ~56px на тёмной подложке) · тип слота (Мелкий, `--text-muted`) ·
название (Основной, цвет по редкости) · 1–2 мода через `·` (Мелкий, `--text-muted`).

### Сводка статов (beta)
Пары «иконка + значение» в строку: резисты (иконка в семантическом цвете, значение
`--text`), рядом за разделителем — Energy Shield. Если резист ниже капа (75%) —
значение `--text-muted` *(предложение: подсветка недокапа)*.
Значения расчётные и приблизительные (моды уникальных заданы диапазонами): рядом с заголовком
маленький бейдж `beta` (граница `--border`, текст `--text-muted`), подсказка «Приблизительный расчёт
по предметам и пассивкам».

### Подсказка (tooltip)
Как на сайте — у предметов, рун и соул-коров, скиллов, саппортов, пассивок. Фон `--surface`,
граница 1px `--border`, скругление 8px, ширина до ~360px. Сверху иконка и название (цвет по редкости
или типу), под ним чипы тегов, затем параметры «ключ: значение», описание (`--text-muted`)
и список эффектов. Появляется с задержкой ~150ms при наведении и при фокусе с клавиатуры,
не выходит за край экрана.

### Список приоритета
Номер в круге (обводка 1px `--accent`, цифра `--accent`) · название (Основной) ·
подсказка (Мелкий, `--text-muted`).

### Строка скилла
Иконка скилла (~40px) · название · теги через `·` · справа ряд иконок саппорт-гемов
(~24px) · шеврон `›`. Выбранная строка — фон `--accent-soft` и полоса 2px `--accent` слева.

### Панель деталей
Заголовок, короткое описание, таблица «ключ — значение» (ключ `--text-muted` слева,
значение `--text` справа), внизу — контурная кнопка.

### Кнопка
Контурная: граница 1px `--accent`, текст `--accent`, стрелка `→` после подписи
(`View Details →`, `View Full Tree →`). Наведение — фон `--accent-soft`.

### Дерево пассивок
В первой версии — дерево самого сайта (его canvas, зум и управление), встроенное в область вкладки;
наши только рамка карточки и боковая панель. Собственная отрисовка — позже: холст на фоне `--bg`,
невзятые ноды — `--border`/`--text-muted`, взятые ноды и путь — `--accent`, кнопки `+`/`−`
и миникарта — в левом нижнем углу.

## 8. Состояния *(предложение)*

| Состояние | Вид |
|---|---|
| Наведение | Фон `--surface-hover`; у текстовых вкладок — текст `--text` |
| Активный / выбранный | Акцентный цвет + `--accent-soft` (см. компоненты) |
| Фокус с клавиатуры | Обводка 2px `--accent` со смещением 2px (`:focus-visible`) |
| Неактивный | Текст `--text-disabled`, без реакции на наведение |
| Загрузка | Скелетоны карточек цвета `--surface-hover` с мягкой пульсацией |
| Нет данных | Приглушённая карточка: «В гайде нет данных для этого раздела» |
| Ошибка разбора | Плашка сверху: «Не удалось прочитать билд» + кнопка «Открыть оригинал» |

Анимации — только короткие переходы 120–160ms (цвет, фон, подчёркивание вкладки);
при `prefers-reduced-motion` — без анимаций.

## 9. Поведение *(предложение)*

- Расширение активируется только на страницах билдов целевого сайта.
- Переключатель **«Оригинал ↔ Расширение»** всегда доступен (кнопка в углу
  и иконка расширения в панели Chrome).
- Состояние в URL-хэше: `#gear_act-1`, `#skills_endgame-full-life` — ссылкой можно поделиться,
  перезагрузка не сбрасывает вкладку.
- Горячие клавиши: `1`–`6` — вкладки, `←`/`→` — варианты в Gear.
- Выбранные вкладка и вариант запоминаются для билда.

## 10. Технические заметки

- Manifest V3, content script на страницах билдов.
- Интерфейс монтируется в **Shadow DOM**, чтобы стили сайта и расширения не влияли
  друг на друга; исходная разметка страницы не удаляется, а скрывается.
- Адрес в концепте (`poe2-builds-extension://build/chaos-dot-lich`) — иллюстрация:
  собственную схему URL Chrome не позволяет. Реальные варианты — оверлей на странице
  сайта (основной) или страница расширения `chrome-extension://<id>/build.html?…`.
- Все шрифты и иконки интерфейса поставляются в пакете расширения.

## 11. Открытые вопросы

Решённые вопросы (сайт, источники данных, дерево) — в [docs/PLAN.md](../docs/PLAN.md).

   показываем оба блока или объединяем.
