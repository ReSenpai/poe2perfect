# Интерфейс расширения — структура экранов

> Визуальная система (цвета, шрифты, компоненты, состояния) описана в [DESIGN.md](DESIGN.md).
> Концепт-арт: [`Концепт расширения для PoE 2 билдов.png`](Концепт%20расширения%20для%20PoE%202%20билдов.png).
>
> Макеты ниже — схемы расположения блоков, а не пиксельные размеры. Названия билда,
> скиллов и предметов — примеры. Вкладок **Overview**, **Atlas Tree** и **Progression**
> в концепте нет; вкладку Notes убрали (решение пользователя): тексты гайда — на Overview, заметки к дереву — в Passives.

## Главное правило

Весь билд — **один экран без длинной прокрутки**. Шапка и панель вкладок закреплены,
меняется только область контента. Никаких длинных секций одна под другой.

Вкладки не дублируют друг друга: в Skills нет экипировки и дерева, в Gear нет гемов,
в Passives длинный текст только в заметках автора (вкладка боковой панели).

## Каркас

```
┌──────────────────────────────────────────────────────────────┐
│ [art]  CHAOS DOT LICH                     High damage over   │
│        Witch / Lich                       time, strong       │
│        League 0.5.5 · Level 70+ · Endgame survivability,     │
│                                           clear speed        │
├──────────────────────────────────────────────────────────────┤
│ [Overview]  Skills   Gear   Passives   Atlas   Progression    │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                    CONTENT OF ACTIVE TAB                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **Шапка:** арт класса/асценданса, название билда, `Класс / Асценданс`, мета-строка
  (лига/патч, уровень, стадия игры) и справа — описание билда в 1–3 строки курсивом.
- **Вкладки:** иконка + подпись. Активная — акцентный цвет и подчёркивание 2px.
- **Контент:** занимает всё оставшееся место; прокрутка допускается только внутри
  отдельной карточки, если данных больше, чем помещается.

## Skills

Слева — список активных скиллов, справа — детали выбранного.

```
┌──────────────────────────────────┬───────────────────────────┐
│ ACTIVE SKILLS                    │ KEY SKILL INFO            │
│                                  │                           │
│▌[ic] Chaos Bolt               ›  │ Chaos Bolt                │
│      Spell · Chaos · AoE         │ Deals chaos damage over   │
│      ○ ○ ○ ○ ○                   │ time to enemies in an area│
│                                  │                           │
│ [ic] Arcanist Brand           ›  │ Damage type         Chaos │
│      Spell · Brand · Support     │ Cast time           0.8 s │
│      ○ ○ ○ ○ ○                   │ Mana cost              28 │
│                                  │ Radius              3.5 m │
│ [ic] Spirit Offering          ›  │                           │
│      Spell · Minion · Buff       │ SUPPORT GEMS              │
│      ○ ○ ○ ○ ○                   │ ○ ○ ○ ○ ○                 │
│                                  │                           │
│ [ic] Flame Wall               ›  │                           │
│      Spell · Fire · AoE          │ [ View Details → ]        │
│      ○ ○ ○ ○ ○                   │                           │
└──────────────────────────────────┴───────────────────────────┘
```

- `▌` — выбранная строка (акцентная полоса слева), `○` — сокеты саппорт-гемов
  (иконки гемов в цвете атрибута), `›` — открыть детали.
- Строка скилла: иконка, название, теги (`Spell · Chaos · AoE`), ряд саппортов.
- Правая панель: название, короткое описание, таблица «ключ — значение»
  (выравнивание значений по правому краю), саппорт-гемы, кнопка **View Details**.
- При первом открытии выбран первый (основной) скилл.

## Gear

Над контентом — переключатель варианта экипировки. Слева — слоты, справа — сводка
защиты и приоритет статов для выбранного варианта.

```
┌──────────────────────────────────────────────────────────────┐
│ [Act 1]  Act 2  Act 3  Act 4–Endgame  Full Life  Low Life    │
├─────────────────────────────────────┬────────────────────────┤
│ GEAR                                │ RESISTANCES            │
│                                     │ F 75  C 75  L 75  X 48 │
│ Helmet  [item]    Weapon  [item]    │ ENERGY SHIELD    4 320 │
│ Body    [item]    Offhand [item]    ├────────────────────────┤
│ Gloves  [item]    Amulet  [item]    │ GEAR PRIORITY          │
│ Boots   [item]    Ring 1  [item]    │                        │
│                   Ring 2  [item]    │ 1  Energy Shield       │
│                   Belt    [item]    │ 2  Chaos Resistance    │
│                                     │ 3  Elemental Res.      │
│                                     │ 4  Cast Speed          │
│                                     │ 5  Intelligence        │
│                                     │ 6  Life Regeneration   │
└─────────────────────────────────────┴────────────────────────┘
```

- **Варианты** (полные подписи): `Act 1`, `Act 2`, `Act 3`, `Act 4 – Endgame`,
  `Endgame Full Life`, `Endgame Low Life`. Список берётся из гайда — показываем
  только те варианты, что есть у билда.
- **Слоты:** левая колонка — броня (Helmet, Body Armour, Gloves, Boots), правая —
  оружие и бижутерия (Weapon, Offhand, Amulet, Ring 1, Ring 2, Belt).
  Карточка слота: иконка предмета, тип слота, название (цвет по редкости),
  1–2 ключевых мода через `·`. Пустой слот — приглушённая карточка «Any».
- **Сводка:** резисты (F — Fire, C — Cold, L — Lightning, X — Chaos) и Energy Shield.
- **Приоритет:** нумерованный список, у каждого пункта — короткая подсказка
  (например, `Energy Shield — Aim for 4k+`, `Chaos Resistance — Cap at 75%`).

## Passives

Максимальная площадь под само дерево, узкая боковая панель ключевых нод.

```
┌───────────────────────────────────────┬──────────────────────┐
│                                       │ KEY PASSIVES         │
│                                       │                      │
│          ·   ·──●──·   ·              │ 1 Corruption Resist. │
│      ·──●       │      ●──·           │   +20% Chaos Res     │
│          ╲  ·──●──·   ╱               │ 2 ES Mastery         │
│     ◎      ●    │    ●      ·         │   +12% increased ES  │
│          ╱  ·──●──·   ╲               │ 3 Darkness Infusion  │
│      ·──●       │      ●──·           │   +25% Chaos Damage  │
│          ·   ·──●──·   ·              │ 4 Arcane Focus       │
│                                       │   +15% Cast Speed    │
│                                       │ 5 Mind Over Matter   │
│ [+]                                   │                      │
│ [−]  [minimap]                        │ [ View Full Tree → ] │
│                                       │                      │
└───────────────────────────────────────┴──────────────────────┘
```

- Дерево: pan (перетаскивание) и zoom (колесо, кнопки `+`/`−`), миникарта в углу.
  Взятые ноды и путь — акцентным цветом, остальные — приглушённые.
- Панель: нумерованный список ключевых нод с их эффектом. Наведение на пункт
  подсвечивает ноду на дереве, клик — центрирует дерево на ней.
- **View Full Tree** — открыть дерево в оригинальном планировщике.
- Если у билда несколько вариантов дерева — тот же переключатель вариантов, что в Gear.

## Atlas Tree

Появляется, только если хотя бы у одного варианта есть дерево атласа. Раскладка как у Passives: дерево сайта
на всю площадь и узкая панель **Key Atlas Passives** — очки и notable/keystone, сгруппированные по под-деревьям
(Atlas, Expedition, Breach…). У варианта без атласа раскладка та же: в области дерева — пояснение (сайт не рисует для него атлас), в панели — «The author hasn't suggested atlas passives for this variant yet».

## Progression

Путь от старта до эндгейма: что меняется на каждой стадии. Стадии — варианты билда в порядке гайда.

```
┌──────────────┬──────────────────────────────────────────┬──────────────┐
│ STAGES       │ ENDGAME (FULL LIFE)  Changes from ACT 4  │ QUEST REWARDS│
│ ACT 1   20 p │ Описание варианта от автора              │ ACT 2        │
│▌ENDGAME 112p │ ┌ SKILLS ─ Open ┐┌ GEAR ─ Open ┐┌ PASS… ┐ │ Medallion    │
│ …            │ │ + Chaos Bolt  ││ Helmet       ││ 112 (+31)│ │ +1 Charm Slot│
│              │ │ − Unearth     ││ ~~Circlet~~  ││ + Melding│ │ ACT 3 …      │
└──────────────┴──────────────────────────────────────────┴──────────────┘
```

- Изменения считаются относительно предыдущего варианта: скиллы и саппорты (+/−), экипировка по слотам
  (было → стало), очки пассивок с разницей, новые ключевые пассивки и асценданс. Первая стадия — «Starting point».
- «Open Skills / Gear / Passives» открывает вкладку с этим вариантом. Чипов вариантов нет — их заменяет список стадий.
- Quest Rewards — награды, выбранные автором, по актам; «Choice» — квест с выбором награды. Нет наград — нет колонки.
